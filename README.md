# MetroidvaniaDemo

Демонстрационный 2D-проект на Godot, созданный как практическая проверка архитектурных принципов для масштабируемой игровой логики. Проект ориентирован на жанр платформера / метроидвании и показывает, как строить игровые системы так, чтобы их было проще расширять и поддерживать.

## О проекте

Это вертикальный срез игры, в котором основной акцент сделан не на объёме контента, а на устройстве кода и взаимодействии систем.  
В основе проекта — идеи про уменьшение лишних зависимостей, более прозрачную коммуникацию между узлами сцены и выделение логики в переиспользуемые модули.

## Что демонстрирует проект

- движение персонажа с базовыми механиками платформера;
- прыжок, двойной прыжок и рывок;
- ближние и дальние атаки;
- систему состояний для игровых сущностей;
- взаимодействие игрока с врагами и препятствиями;
- подход к организации сцен и скриптов без лишней связанности.

## Архитектурные идеи

Проект опирается на несколько практических правил:

- дочерние узлы не зависят от внешнего мира сильнее, чем нужно;
- корневой узел отвечает за оркестрацию взаимодействий внутри сцены;
- коммуникация между объектами строится через сигналы и явные зависимости;
- избыточные абстракции не добавляются заранее без практической необходимости;
- общая логика, которую нужно переиспользовать, выносится в отдельные классы.

Для состояний используется отдельная иерархия классов, а общие расчёты движения вынесены в вспомогательный модуль. Это помогает держать код компактным и понятным при росте количества механик.

## Сюжетная и игровая основа

Сеттинг — 2D action-adventure в стилистике сказочной Европы викторианской эпохи, где сочетаются магия и технологии.  
Главная героиня — наёмный детектив, который исследует магические преступления и получает новые возможности через найденные артефакты.

## Управление

- **A / D** — движение влево и вправо
- **K** — прыжок
- **L** — рывок
- **J** — ближняя атака
- **U** — дальняя атака
- **Esc** — меню / пауза

## Технологии

- Godot Engine
- GDScript
- Git

## Структура репозитория

- `Assets` — графика, анимации и прочие ресурсы
- `Entity` — сущности игры и их логика
- `Node` — узлы и компоненты сцены
- `RefCounter` — классы для переиспользуемой логики
- `Scenes` — игровые сцены

## Запуск

1. Установить Godot 4.x.
2. Открыть проект через `project.godot`.
3. Запустить основную сцену из редактора.
